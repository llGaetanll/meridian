Sketches / Data coverage

An internal page, mine alone: how much of the market data we mean to hold is actually in prod's database. Not the web app and not in it — the drawing is a small read-only tool that runs on the laptop, reads prod's Postgres through the tunnel, and binds to localhost, so the page exists only where it is run. Three states, everywhere on the page: collected is plain ground with the curve on it, not collected is the amber wash — bars we could ask for and have not — and unavailable is the hatch, the same hatch the asset chart uses for a shut market: hours Yahoo cannot answer for, because the symbol was not listed yet, the interval's history floor has passed, or the bar is still forming. Coverage is kept per symbol and interval, so the page reads one interval at a time. The activity bar has no table behind it yet — the server does not remember when it asked Yahoo — so that part of the drawing is also a proposal for one.
