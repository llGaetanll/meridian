# one `SYMBOL WEIGHT` per line — the hundred biggest names by dollar volume.
#
# A weight is a prior, not a reading — coarse relative dollar volume, good
# enough to say SPY before a small-cap. Only ratios matter, and stale
# rankings cost only a suboptimal fetch order. The weight also decides the
# interval ladder a symbol earns, relative to the heaviest line: the top
# tier gets minute bars, the middle quarter-hours, the tail daily only.
#
# The whole file is refused if any line does not parse, so a typo is a
# startup warning rather than a silently thinner universe.
